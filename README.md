# tidyquant lightning talk

Lightning talk for CSI 2300 at Baylor, Spring 2026.

Tests two investment strategies: market timing and stock 
picking against the S&P 500 from April 2021 to April 2026 using
the tidyquant R package.

## Files
- `LT.qmd` — source Quarto file for the talk
- `LT.html` — rendered slides 
- `TQ05-performance-analysis-with-tidyquant.Rmd` — original tidyquant vignette
